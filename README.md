# 🔍 WikiLens — Wikipedia連想ゲーム（6回勝負）

Wikipediaの象徴的な「画像」や「冒頭の文章」から、対象記事（抽象概念など）を推理する日替わりWebブラウザゲームです。  
最大6回の挑戦で正解との意味的距離（距離0で正解！）を手がかりに、記事名の特定を目指します。

## 🎮 ゲームルール

1. **挑戦は1問あたり最大6回まで**:
   - 画面上部の6つのスロット（Wordle風）で残り回数を管理。
   - 辞書にない単語は回数を消費しません。
2. **正解との距離（距離0が正解！）を判定**:
   - 推測した単語を入力すると、AIモデルが正解との意味的距離（0〜約20,000）を即時判定。
   - 距離0で正解・ゲームクリアとなります。
3. **2つの出題形式（ハイブリッド）**:
   - **🖼️ 画像版**: 象徴的な画像が表示される問題（例: 懐中時計 → 正解「時間」）。
   - **📝 文字版**: 代表画像のない抽象概念（孤独、記憶、意識、愛、情報など）を対象に、冒頭の文章から推理する問題。
4. **3回目の挑戦から順次開放される段階的ヒント（全4段階）**:
   - **3回目挑戦時（2個入力後）**: 🏷️ 記事の所属カテゴリ（文字版なら第2文が開放）
   - **4回目挑戦時（3個入力後）**: 🔤 記事名の文字数
   - **5回目挑戦時（4個入力後）**: 📑 目次構成（セクション一覧 / 文字版なら第3文が開放）
   - **6回目挑戦時（5個入力後・ラストチャンス）**: 💡 最初の文字（頭文字）＆ 📝 導入部の伏せ字抜粋
   - **6回終了時**: 終了（正解とWikipedia解説を開示）
5. **毎日の日替わり更新 (JST 00:00)**:
   - 日本時間の毎日深夜0時（15:00 UTC）に GitHub Actions により自動で新しい問題が公開されます。

## ✨ システムアーキテクチャ・特長

- **完全0円運用（静的ホスティング＋事前バッチ計算）**
  - 推論APIやバックエンドサーバーを一切使わず、ローカル／CIで事前計算した静的JSONとHTML/CSS/Vanilla JSのみで動作します。
- **ネタバレ防止＆Wikimedia規約準拠**
  - 画像は日付ID名（`./data/images/YYYY-MM-DD.jpg`）で保存され、URLやファイル名から正解が漏洩しません。
  - Creative Commonsライセンス（CC BY-SA等）の著作者・ライセンス種別・元ファイルリンクを明記しています。
  - 公開日を迎えていない未来の問題データは公開マニフェストに含まれません。
- **高精度セマンティックランキング**
  - 多言語埋め込みモデル `intfloat/multilingual-e5-small` による意味類似度とWikipedia内部リンクを組み合わせた約20,000語のランキングを $O(1)$ で高速判定します。
- **表記ゆれ・リダイレクト対応**
  - Wikipediaのリダイレクトや読み仮名（例：「じかん」「タイム」）も正解として判定します。

## 🚀 ローカル起動方法

```bash
python3 -m http.server 8000
```
ブラウザで `http://localhost:8000` を開いてプレイできます。

## 🛠️ 問題生成・公開スクリプト

```bash
# プリセット10問（画像版＋文字版）の一括生成
uv run --python 3.11 --with-requirements requirements.txt python3 scripts/generate_problem.py --preset

# 日付と記事名を指定して1問生成（自動判別または mode 指定）
uv run --python 3.11 --with-requirements requirements.txt python3 scripts/generate_problem.py \
  --date 2026-10-24 \
  --title "自由" \
  --mode auto

# 本日分の公開処理（JST 00:00 自動公開スクリプト）
python3 scripts/release_today.py
```
